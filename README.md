# Glass Root Landscape Studio v0.1

An independent, stylized landscape concept editor. Open `index.html` in Chrome or Edge; no installation, dependencies, network requests, accounts, or paid assets. All symbols are original procedural drawings. The 3D concept mode is an orthographic projection, not a mesh-based photorealistic renderer.

## Start
- Click Example to explore a sample layout, or New for a blank property.
- Use 2D plan for most drawing: place plants, draw polygon beds (Finish bed or Enter), draw rectangular buildings and paths with two corners, measure with two clicks.
- Select/move objects, edit dimensions, duplicate/delete; Space + drag or middle mouse pans; wheel zooms.
- Switch to 3D concept and rotate the view. Save project JSON for durable backups; Open JSON restores an exported file. Browser local storage is best-effort and may be cleared.
- Export PNG of the active view and CSV plant quantities.

## Boundaries
Example species sizes are editable concept assumptions, not validated dimensions, BONAP county records, or planting recommendations. Flat terrain; straight-edged polygon beds; rectangular buildings and paths; approximate 3D painter ordering. No geographic data, pricing, ecological analysis, custom species editor, or construction documentation yet. Not a CAD/survey tool. A project may extend outside property bounds if objects are moved or resized.

## Next phase
Test workflow with actual designs; add curved paths/beds, better editing/handles, labels and dimensions, materials, planting mass tools, and a verified regional species library. Keep all assets original or license-compatible; no proprietary assets copied.

## Hosting
Create an independent GitHub repository `Glass-Root-Landscape-Studio`, upload these files, and optionally enable GitHub Pages on the main branch (root). Public Pages availability depends on repository visibility and account settings. Do not put client addresses or designs into a public repository.
