## Native-first palette policy — owner direction

- Prioritize straight species native to Hays County and the owner's selected surrounding counties, then other Texas natives and carefully selected nearby-region natives. Confirm county distribution using BONAP/NAPA before assigning local-native labels. Do not equate Texas-native with Hays-native. Range expansion and exact county boundaries remain to be coordinated.
- Selected nonnative ornamentals may eventually be added in a separate opt-in category after screening. Clearly identify origin, taxon/cultivar identity and evidence; never imply equal ecological value or a native designation. Unreviewed status is not a safety claim.
- Screen proposed additions against [Texas Invasives](https://www.texasinvasives.org/plant_database/), [Texas Department of Agriculture regulated list](https://texasagriculture.gov/Regulatory-Programs/Plant-Quality/Noxious-and-Invasive-Plants), and relevant regional evidence. Absence from the regulated list does not establish noninvasiveness. Exclude known invasive taxa from normal planting recommendations; any future existing-site inventory/removal visualization must be explicitly labeled, separated from recommended palette and respect applicable restrictions. No exotic species added or current palette recategorized in this batch. Main Studio UI implementation requires coordination.
- Private pricing and Professional Studio deferred at owner's request.

## Consumer API

```js
import {findPlantModel, buildPlantModel, createPlantGeometry, plantModels} from './plant-models/registry.js';
const model = findPlantModel('p1'); // or exact scientific name
const geometry = createPlantGeometry(THREE, model.id, {
  seed: 42, stage: 'mature', detail: 'medium'
});
// Geometry is normalized by default. Scale to saved object dimensions in feet:
// mesh.scale.set(object.w, object.height, object.w);
// Material: white, vertexColors:true, side:THREE.DoubleSide.
// Dispose and reuse geometry in the Studio's existing instancing pipeline.
```

Use the caller's pinned Three.js r180 namespace. The generator itself has no engine dependency. Returned attributes are non-indexed Float32Array positions, normals and colors, three components each. Coordinates are Y-up, origin at the base. Default buildPlantModel units are meters; createPlantGeometry defaults to normalized spread and height. Normalization uses twice maximum absolute horizontal coordinate and maximum Y, with inverse-transpose normal correction. It fits the supplied stage/detail bounds independently; visual state changes can therefore alter relative foliage proportions in a fixed-height project instance. Linear sRGB vertex colors default for Three.js; display RGB preserves the old raw WebGL preview. Do not normalize or convert colors twice.

Stages: leafy, young, mature, fall, dry; illustrative, not calendar phenology. Detail: high, medium, low. Mass proxy not supplied yet; retain Studio's existing fallback for mass scenes. Seed is uint32; lab exposes five fixed seeds. Registry exact scientific names and palette IDs: p1 Muhlenbergia lindheimeri, p0 Schizachyrium scoparium, p6 Salvia greggii. Unknown keys return null from findPlantModel and throw from buildPlantModel. All registered species are prototypes, not production approved. Studio has an opt-in shared registry comparison path; browser review is pending. Source notes remain in lab and registry; no source photos copied, no new county nativity decision.
